==Оптимизация сайта== - работа с кодом и текстом web-страниц, имеющая целью использование совокупности внутренних факторов, применяемых на странице веб-сайта, оказывающих влияние на результат выдачи по данному поисковому запросу.
==Продвижение сайтов== - комплекс мероприятий, направленный на изменение внешних факторов, влияющих на результат выдачи по данному поисковому запросу или опосредованно связанных с поисковой выдачей.
==Раскрутка сайтов== - привлечение посетителей на сайт Заказчика способами, не связанными с результатами выдачи поисковых машин по данному запросу.
1.  Поисковое продвижение (SEO)
2. Платная реклама (SEM/PPC)
3. Маркетинг в социальных сетях (SMM) 
4. Контент-маркетинг 
5. Email-маркетинг


## **SEARCH ENGINE OPTIMIZATION (SEO)**

==SEO== - комплекс действий по внутренней и внешней оптимизации, направленных на повышение позиций сайта в поисковой выдаче.
##### Принципы поисковой оптимизации.

Факторы -> Релевантность (соответствие по определенному признаку. Насколько страница сайта соответствует поисковому запросу.) -> Выдача

Факторы ранжирования - это критерии оценки сайтов (в целом и их отдельных элементов), которые используют поисковые системы для того, чтобы формировать релевантную поисковую выдачу.

Характеристика поисковых запросов

1) По намерению:
Навигационные.
Информационные.
Коммерческие.
Транзакционные.
Медиа
Неопределенные
2) По частности:
Высокочастотные
Среднечастотные
Низкочастотные
3) Конкурентность:
Высоконкурентные
Низкоконкурентные 

4) По геозависимости:
С топонимом(названием нас пункта, региона)
Без топонима

Семантическое ядро

==Подбор семантического ядра== - процесс сбора поисковых запросов, которые представляют ценность для нашего проекта, поскольку могут привести целевую аудиторию.

Структура, сформированная на основе семантики:
Поисковые запросы
Структура сайта
Контент



**Белое СЕО** - использование методов, которые разрешены и одобрены поисковыми системами.
**Чёрное СЕО** - использование запрещённых методов.

**Клоакинг** - сайт конструируется таким образом, чтобы поисковые роботы "видели" один контент (безобидный), а пользователи - другой (запрещённый).

**Дорвеи** - пользователи попадают сначала на одну страницу (с безобидным контентом), а оттуда идёт автоматическое перенаправление на страницу с запр контентом.

**Внутренний поисковой спам** - контент переполняется ключевыми словами в объемах, которые превышают разумные пределы, за счёт чего искусственно поднимается релевантность.

**Ссылочный спам** - на сайт направляется большое количество ссылок со сторонних ресурсов.

**Невидимый текст** - текст, который не виден для живых пользователей, но индексируется поисковыми роботами.
