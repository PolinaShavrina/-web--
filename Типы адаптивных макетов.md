Вот конспект презентации «Типы адаптивных макетов»:

## 1. Размеры экранов (брейкпоинты)
Основные контрольные точки: **375 px** (смартфон), **960 px** (планшет), **1200 px** (ноутбук), **1920 px** (десктоп).

## 2. Типы адаптивных макетов

| Тип | Суть | Плюсы | Минусы | Примеры |
|---|---|---|---|---|
| **«Малой кровью»** | Простое масштабирование изображений и типографики | Очень простой | Негибкий, не популярен | Future Friendly, Path |
| **Резиновый** | Блоки сжимаются до ширины экрана, при невозможности — перестраиваются в одну ленту | Простой в реализации, очевиден для пользователя, легко через Bootstrap | Средняя гибкость | Five Simple Steps, Trent Walton |
| **Перенос блоков** | При уменьшении ширины дополнительные блоки (сайдбары) переносятся вниз | Очевиден для многоколоночных сайтов | — | Modernizr, Owltastic |
| **Переключение макетов** | Под каждое разрешение — отдельный макет | Наиболее удобен при чтении с разных устройств | Трудоёмкий, менее популярен | The Boston Globe, Food Sense |
| **Панели** | Доп. меню появляется по тапу (из мобильных приложений) | Гибкий | Неочевиден для пользователя на веб-сайтах | Kaemingk Christmas 2012 |

## 3. Что использовать?
- **Простой сайт** → «малой кровью» или резиновый
- **Блог / лендинг** → перенос блоков
- **Крупный портал** → переключение макетов
- **Мобильное приложение / SPA** → панели
- **Быстрый старт** → Bootstrap (резиновый + перенос)

### Сравнительная таблица

| Тип | Сложность | Гибкость | Популярность |
|---|---|---|---|
| Резиновый | Низкая | Средняя | Высокая |
| Перенос блоков | Низкая | Средняя | Высокая |
| Переключение макетов | Высокая | Высокая | Низкая |
| «Малой кровью» | Очень низкая | Низкая | Средняя |
| Панели | Средняя | Высокая | Растёт |

## 4. Принципы адаптивной вёрстки
- **Брейкпоинты** — значения ширины экрана, при которых меняются CSS-стили и расположение блоков.
- **Относительные единицы** — `%`, `vw`, `vh`, `rem` вместо `px`.
- **Гибкие сетки** — Flexbox и CSS Grid.
- **Медиазапросы** — правила `@media` в CSS.

## 5. Инструменты
- **Flexbox** — модуль для гибкого выстраивания элементов в строку/колонку.
- **CSS Grid** — двумерная система компоновки (строки + столбцы).
