# Правила семантической вёрстки

Семантическая вёрстка — это подход, при котором HTML-теги используются по их смысловому назначению, а не только для визуального оформления. Это улучшает доступность, SEO и поддерживаемость кода.

---

## 1. Основные принципы

- **Смысл важнее внешнего вида** — тег должен описывать *что это*, а не *как это выглядит*.
- **Не используйте `<div>` и `<span>` там, где есть подходящий семантический тег.**
- **Структура документа должна быть понятна без CSS.**
- **Код должен быть понятен человеку и машине (поисковику, скринридеру).**

---

## 2. Структурные теги (layout)

| Тег | Назначение |
|---|---|
| `<header>` | Шапка сайта или раздела |
| `<nav>` | Блок навигации (меню) |
| `<main>` | Основное содержимое страницы (один на страницу) |
| `<aside>` | Боковая панель, дополнительный контент |
| `<footer>` | Подвал сайта или раздела |
| `<section>` | Тематический раздел (обычно с заголовком) |
| `<article>` | Независимая единица контента (статья, пост, карточка товара) |

**Пример:**
```html
<body>
  <header>
    <nav>...</nav>
  </header>
  <main>
    <article>
      <h1>Заголовок статьи</h1>
      <p>Текст...</p>
    </article>
    <aside>Похожие статьи</aside>
  </main>
  <footer>© 2026</footer>
</body>
```

---

## 3. Текстовые теги

| Тег | Назначение | Не путать с |
|---|---|---|
| `<h1>`–`<h6>` | Заголовки по уровням | `<div class="title">` |
| `<p>` | Абзац текста | `<br><br>` |
| `<strong>` | Важность (жирный) | `<b>` (просто жирный) |
| `<em>` | Акцент (курсив) | `<i>` (просто курсив) |
| `<blockquote>` | Цитата блока | `<q>` (короткая цитата в строке) |
| `<code>` | Фрагмент кода | `<pre>` (блок кода с сохранением пробелов) |
| `<mark>` | Выделенный текст | — |
| `<time>` | Дата/время | — |
| `<address>` | Контактная информация | — |

---

## 4. Списки

- `<ul>` — маркированный список
- `<ol>` — нумерованный список
- `<dl>`, `<dt>`, `<dd>` — список определений (термин → описание)

**Не используйте списки только для отступов** — для этого есть CSS.

---

## 5. Изображения и медиа

| Тег | Назначение |
|---|---|
| `<img>` | Изображение (обязателен `alt`) |
| `<figure>` | Иллюстрация с подписью |
| `<figcaption>` | Подпись к `<figure>` |
| `<picture>` | Адаптивное изображение |
| `<video>`, `<audio>` | Медиа с управлением |
| `<track>` | Субтитры |

**Пример:**
```html
<figure>
  <img src="cat.jpg" alt="Рыжий кот спит на подоконнике">
  <figcaption>Рис. 1. Кот после обеда</figcaption>
</figure>
```

---

## 6. Формы

- `<form>` — форма
- `<fieldset>` + `<legend>` — группировка полей
- `<label for="...">` — подпись к полю (обязательно связывать с input)
- `<input>`, `<textarea>`, `<select>`, `<button>`
- `<datalist>` — автодополнение
- `<output>` — результат вычислений

**Правило:** у каждого поля должна быть доступная подпись (`label`, `aria-label` или `aria-labelledby`).

---

## 7. Интерактивные элементы

| Тег | Когда использовать |
|---|---|
| `<button>` | Действие (отправить, открыть, переключить) |
| `<a>` | Переход по ссылке |
| `<details>` + `<summary>` | Раскрывающийся блок без JS |
| `<dialog>` | Модальное окно |

**Не делайте кнопку из `<div>`** — теряется доступность (фокус, клавиатура, скринридеры).

---

## 8. Доступность (a11y)

- Всегда указывайте `alt` у изображений (пустой `alt=""` — для декоративных).
- Используйте `aria-*` атрибуты только когда HTML-тегов недостаточно.
- Соблюдайте иерархию заголовков (`h1` → `h2` → `h3`, без пропусков).
- Обеспечьте навигацию с клавиатуры (`Tab`, `Enter`, `Space`).
- Контраст текста — не ниже 4.5:1.
- У форм — `<label>`, у таблиц — `<caption>` и `<th scope>`.

---

## 9. SEO-преимущества

- Поисковики лучше понимают структуру страницы.
- `<h1>` и `<h2>` влияют на ранжирование.
- `<article>`, `<time>`, `<address>` помогают в микроразметке.
- `<nav>` и `<main>` улучшают индексацию.

---

## 10. Частые ошибки

| Ошибка | Как правильно |
|---|---|
| `<div class="header">` | `<header>` |
| `<div class="nav">` | `<nav>` |
| `<div onclick="...">` | `<button>` |
| `<b>` для важности | `<strong>` |
| `<i>` для акцента | `<em>` |
| Несколько `<h1>` на странице | Один `<h1>`, остальные — `<h2>`–`<h6>` |
| `<br>` для отступов | CSS `margin` / `padding` |
| `<table>` для вёрстки | Flexbox / Grid |
| `<img>` без `alt` | Всегда указывать `alt` |

---

## 11. Чек-лист семантической вёрстки

- [ ] Структура: `header`, `nav`, `main`, `footer` на месте
- [ ] Заголовки идут по порядку, без пропусков
- [ ] Каждое изображение имеет `alt`
- [ ] Формы связаны с `label`
- [ ] Кнопки — это `<button>`, ссылки — `<a>`
- [ ] Списки — это `<ul>` / `<ol>` / `<dl>`
- [ ] Нет `<div>` там, где есть семантический тег
- [ ] Таблицы используются только для данных
- [ ] Есть `<time>` для дат, `<address>` для контактов
- [ ] Страница доступна с клавиатуры и скринридера
